MEASUREMENT THEORY

Stevens' Measurement Scales: NOIR Taxonomy

Stanley Smith Stevens (1946): The mathematical nature of data dictates which statistical operations are strictly valid.

NOIR FRAMEWORK
SCALE 01 · QUALITATIVE Flip ⟳

Nominal Scale

Categorical labels without inherent order or quantitative distance. Numbers assigned are purely arbitrary identifiers (identity only).

Valid Stats: Mode, Contingency Tables, $\chi^2$ Test
Invalid: Mean, Median, Addition, Subtraction
Blood Type (A, B, O) Marital Status ICD-9 Diagnosis
CRITICAL PITFALL

Ordinal Encoding Fallacy

Encoding Nominal data with LabelEncoder (e.g. Red=0, Blue=1, Green=2) tricks algorithms into learning that Green is mathematically "twice" as large as Blue, injecting artificial bias.

SCALE 02 · QUALITATIVE Flip ⟳

Ordinal Scale

Categories possess a meaningful hierarchical sequence or ranking, but the mathematical interval between adjacent ranks is non-uniform or unknown.

Valid Stats: Median, Percentiles, Spearman's $\rho$, Mann-Whitney
Invalid: Arithmetic Mean, Standard Deviation
Cancer Stage (I, II, III, IV) Likert Scales Education Level
EVALUATION INSIGHT

Why Mean is Forbidden

The physiological distance between Stage I and Stage II cancer is not equal to the distance between Stage III and Stage IV. Calculating a "Mean Cancer Stage of 2.4" is statistically meaningless.

SCALE 03 · QUANTITATIVE Flip ⟳

Interval Scale

Numeric values with meaningful, uniform distances between points, but possessing an arbitrary zero point (no absolute absence of the property).

Valid Stats: Mean, Variance, Pearson's $r$, t-test, ANOVA
Invalid: Ratios ("$20^\circ\text{C}$ is not twice as hot as $10^\circ\text{C}$")
Celsius / Fahrenheit Calendar Dates IQ Scores
RATIO PROHIBITION

Arbitrary Zero Meaning

Because $0^\circ\text{C}$ is merely the freezing point of water and not the total absence of thermal energy (Absolute Zero = $-273.15^\circ\text{C}$), multiplicative ratios are mathematically false.

SCALE 04 · QUANTITATIVE Flip ⟳

Ratio Scale

Numeric values with uniform intervals AND a true absolute zero point representing total absence. All mathematical and algebraic operations are fully valid.

Valid Stats: Geometric Mean, Coefficient of Variation, Full Linear Algebra
Properties: $40\text{ mg/dL}$ is strictly twice as large as $20\text{ mg/dL}$
Glucose mg/dL Blood Pressure Age / Weight Kelvin
THE ULTIMATE SCALE

Maximum Statistical Power

Ratio scale features allow log-transformations, percentage change modeling, and unconstrained dimensional scaling in machine learning feature stores.

MISSING DATA THEORY

Rubin's Missingness Taxonomy (1976)

Donald Rubin: The validity of imputation depends entirely on the latent mechanism driving data absence.

MCAR / MAR / MNAR
MECHANISM 01 Flip ⟳

MCAR (Completely at Random)

Missingness probability is purely stochastic and completely unrelated to any observed or unobserved variable:

$P(M | Y_{\text{obs}}, Y_{\text{mis}}) = P(M)$

Analogy: A laboratory test tube randomly dropped and shattered on the clinic floor.

Listwise Deletion Safe Mean / Median Imputation
IMPUTATION ACTION

Treatment Rules

If MCAR missingness is <5% of rows, listwise deletion retains unbiased estimators. If imputing, use Median (for skewed variables) or Mean (for normal variables).

MECHANISM 02 Flip ⟳

MAR (Missing at Random)

Missingness probability depends on observed covariates in the dataset, but not on the missing value itself:

$P(M | Y_{\text{obs}}, Y_{\text{mis}}) = P(M | Y_{\text{obs}})$

Analogy: Young patients are less likely to report blood pressure, but within age cohorts missingness is random.

Conditional Imputation MICE / KNN
IMPUTATION ACTION

Treatment Rules

Mean imputation produces severe bias! Impute conditionally using Group-Wise Medians (grouped by observed predictors), MICE (Chained Equations), or KNN regression.

MECHANISM 03 Flip ⟳

MNAR (Not at Random)

Missingness probability depends directly on the latent unobserved missing value itself:

$P(M | Y_{\text{obs}}, Y_{\text{mis}}) = P(M | Y_{\text{mis}})$

Analogy: Wealthiest executives refusing to report income; severe depression patients skipping questionnaires.

Informative Missingness Missing Indicator
FATAL VULNERABILITY

Treatment Rules

Standard statistical imputation is impossible without external domain models. You must create an explicit Missingness Indicator column ($X_{\text{missing}} \in \{0, 1\}$) and impute with neutral sentinel values.

HYPOTHESIS-DRIVEN AUDITING

Testing Missingness: Little's MCAR Test

Roderick Little (1988): Replacing visual eyeballing with rigorous multivariate likelihood ratio tests.

STATISTICAL TEST
GLOBAL DATASET TEST Click to Flip ⟳

Little's Multivariate MCAR Test

Tests whether observed missing data patterns across all variables simultaneously deviate significantly from random expectation:

$d^2 = \sum_{j=1}^J N_j (\bar{y}_{\text{obs}, j} - \hat{\mu}_{\text{obs}, j})^T \hat{\Sigma}_{\text{obs}, j}^{-1} (\bar{y}_{\text{obs}, j} - \hat{\mu}_{\text{obs}, j}) \sim \chi^2(df)$

Null Hypothesis ($H_0$): The missing data mechanism is Missing Completely at Random (MCAR).

Alternative Hypothesis ($H_1$): The mechanism is NOT MCAR (it is MAR or MNAR).

Decision Rule: If $p > 0.05 \rightarrow$ Fail to reject $H_0$ (Safe to assume MCAR). If $p \le 0.05 \rightarrow$ Reject $H_0$ (Data is MAR or MNAR!).

One Global p-value Likelihood Ratio Covariance Matrix
PYTHON IMPLEMENTATION Click to Flip ⟳

PyMCAR Library Execution

Executing Little's test in production Jupyter notebooks:

from pyampute.exploration.mcar_statistical_tests import MCARTest
test = MCARTest(method="little")
p_val = test.little_mcar_test(df[numeric_cols])

If $p < 0.001$, never use simple mean imputation! You have proven statistically that missingness is correlated with underlying features.

STEP 2: IF NOT MCAR Click to Flip ⟳

Column-by-Column Missingness Testing

When Little's test rejects MCAR ($p < 0.05$), create a binary missingness indicator column: $R_i = 1$ if feature is missing, $R_i = 0$ if observed.

Continuous Features ➔ Two-Sample t-Test (or Welch's)
Categorical Features ➔ $\chi^2$ Test of Independence
DIAGNOSTIC CRITERIA Click to Flip ⟳

Proving MAR vs. MNAR

If the missing indicator $R_{\text{income}}$ is significantly associated with Age ($p < 0.01$ on t-test), you have proven the variable is MAR conditioned on Age! Impute income using conditional regression on Age.

STRATEGIC IMPUTATION Click to Flip ⟳

The Imputation Decision Tree

• MCAR + Normal: Mean Imputation
• MCAR + Skewed: Median Imputation
• MAR: Group-Wise Median / MICE / KNN
• MNAR: Missingness Indicator + Sentinel / "Unknown"

VARIANCE COLLAPSE WARNING Click to Flip ⟳

Why Mean Imputation Destroys Variance

Imputing hundreds of identical mean values artificially shrinks sample variance $\sigma^2 \rightarrow 0$ and artificially inflates Pearson correlations, causing downstream models to overfit false peaks.

ANOMALY GEOMETRY

Outlier Treatment: 1.5×IQR Fences & Winsorization

John Tukey's non-parametric fences vs. leverage capping for robust parametric modeling.

OUTLIER TREATMENT
TUKEY'S BOXPLOT FENCES Flip ⟳

1.5×IQR Non-Parametric Geometry

Does not assume a Gaussian normal distribution. Identifies extreme leverage points using quartile boundaries:

$\text{IQR} = Q_3 - Q_1$
$\text{Lower Fence} = Q_1 - 1.5 \times \text{IQR}$
$\text{Upper Fence} = Q_3 + 1.5 \times \text{IQR}$
$\text{Extreme Outliers} > Q_3 + 3.0 \times \text{IQR}$
  • Why 1.5? In a normal distribution, $1.5 \times \text{IQR}$ corresponds to $\pm 2.7\sigma$, capturing $99.3\%$ of legitimate Gaussian data.
  • Outlier Flag: Any observation beyond the fences is marked for audit.
DANGER OF BLIND DROPPING

Never Drop Without Domain Audit

In clinical data, an extreme blood glucose reading of $500\text{ mg/dL}$ is not an entry error—it is an acute diabetic ketoacidosis emergency! Dropping it removes the exact life-threatening event the model was built to predict.

LEVERAGE MITIGATION Flip ⟳

Winsorization Capping (Charles Winsor)

Instead of discarding high-leverage rows and sacrificing statistical power, Winsorization clamps values beyond specific percentiles:

$x_{\text{capped}} = \begin{cases} P_{0.05} & \text{if } x < P_{0.05} \\ x & \text{if } P_{0.05} \le x \le P_{0.95} \\ P_{0.95} & \text{if } x > P_{0.95} \end{cases}$
  • Sample Size Preservation: Retains 100% of rows ($N$ remains constant).
  • Mitigates OLS Leverage: Prevents single extreme outliers from tilting the regression slope $\hat{\beta}_1$.
TRIMMING VS WINSORIZING

When to Trim vs. Cap

• Trim (Delete): Only when verified as physical measurement error or sensor failure.
• Winsorize (Cap): When value is biologically/financially valid but mathematically extreme, ensuring model stability.

FEATURE ENGINEERING

Feature Scaling: Normalization vs. Standardization

Mathematical implications for distance-based algorithms, gradient descent, and regularization penalties.

SCALING COMPARISON
BOUNDED RESCALING Flip ⟳

Min-Max Normalization

Rescales feature values to a strict bounded interval, typically $[0, 1]$:

$x' = \frac{x - x_{\min}}{x_{\max} - x_{\min}}$
  • When to Use: Neural networks (sigmoid/tanh activations), image pixel intensities $[0, 255]$, KNN, K-Means.
  • Fatal Flaw: Extreme outliers compress all normal data into a microscopic fraction (e.g. $[0, 0.05]$).
OUTLIER COMPRESSION

The Vanishing Variance Disaster

If income ranges from $20k to $100k, but one billionaire ($1B) is in the dataset, all 99.9% of citizens are compressed between $0.00002$ and $0.00010$, destroying the model's ability to discriminate between middle-class earners.

MOMENT RESCALING Flip ⟳

Z-Score Standardization

Centers feature mean at 0 and scales standard deviation to 1. Unbounded output:

$z = \frac{x - \mu}{\sigma} \sim \mathcal{N}(0, 1)$
  • When to Use: PCA (variance maximization), SVM, Logistic Regression, Ridge ($L_2$) and Lasso ($L_1$).
  • Robust Scaler Alternative: $x' = \frac{x - Q_2}{\text{IQR}}$ (Centered at median, impervious to outliers).
REGULARIZATION EQUALITY

Why Regularization Mandates Z-Scores

Ridge penalizes $\lambda \sum \beta_j^2$. If Income is measured in dollars ($10^5$) and Age in years ($10^1$), the coefficient for Age must be $10^4$ larger, so Ridge penalizes Age 100,000,000× more! Standardization equalizes penalty pressure across all features.

FEATURE REPRESENTATION

Categorical Encoding & The Dummy Variable Trap

Preventing linear algebra singularities ($k-1$ encoding) and respecting ordinal structures.

ENCODING DYNAMICS
MATHEMATICAL SINGULARITY Click to Flip ⟳

The Dummy Variable Trap

When encoding a nominal feature with $k$ distinct categories into $k$ binary dummy columns in a model containing an intercept term $\beta_0$:

$D_1 + D_2 + \dots + D_k = 1 = x_0 \quad (\text{Perfect Multicollinearity})$

The Proof: The sum of the dummy columns exactly equals the constant column vector $x_0$ representing the model intercept.

Matrix Inversion Failure: The design matrix $X$ has linearly dependent columns, making $X^TX$ non-invertible ($\det(X^TX) = 0$). Ordinary Least Squares $\hat{\beta} = (X^TX)^{-1}X^TY$ fails completely.

The Remedy: Drop one reference category! Always create strictly $k-1$ dummy columns (`pd.get_dummies(..., drop_first=True)`).

drop_first=True Matrix Determinant Zero Reference Category
INTERPRETING k-1 COEFFICIENTS Click to Flip ⟳

How to Read the Reference Baseline

When dropping "Caucasian" as the reference baseline in hospital readmission models:

$\hat{y} = \beta_0 + \beta_1 D_{\text{AfricanAmerican}} + \beta_2 D_{\text{Hispanic}}$

$\beta_0$ represents the baseline outcome for Caucasian patients. $\beta_1$ represents the exact differential impact of being African American compared to the baseline.

ORDINAL MAPPING Click to Flip ⟳

Ordinal / Label Encoding

Maps hierarchical categories to integer increments ($0, 1, 2, \dots$):

Education: High School=0, BS=1, MS=2, PhD=3

Appropriate ONLY when the monotonic ordering reflects true underlying domain severity or capability.

TARGET ENCODING Click to Flip ⟳

High-Cardinality Target Encoding

For features with 10,000 categories (Zip codes, ICD-9 codes) where One-Hot explodes matrix dimensions, replace each category with the average target probability $P(Y=1|\text{Category})$, with m-estimate smoothing to prevent target leakage.

PRODUCTION CHECK Click to Flip ⟳

Unseen Category Handling

What happens if a new category appears during live inference that was absent in training? OneHotEncoder with `handle_unknown='ignore'` outputs all zeros, preventing API crashes.

FAIL-SAFE PIPELINE Click to Flip ⟳

Scikit-Learn ColumnTransformer

Always wrap categorical encoders in a `ColumnTransformer` inside an end-to-end `Pipeline`. Never fit encoders on the entire dataset prior to train-test splitting to prevent target leakage.

STATISTICAL INFERENCE

Parametric LINE+M Assumptions

Gauss-Markov Theorem: Linear models are BLUE (Best Linear Unbiased Estimator) only if LINE+M hold.

LINE+M PROTOCOL
L

Linearity

Relationship between predictors and response is linear in parameters.

Residual Plot vs $\hat{y}$
Polynomial Term
AUDIT

If residuals form a parabolic bowl, linearity is violated. Apply log or quadratic transformations.

I

Independence

Observations and error residuals are mutually uncorrelated.

Durbin-Watson $\approx 2.0$
Autocorrelation
AUDIT

$DW < 1.5$ indicates positive serial correlation. Common in longitudinal patient visits.

N

Normality

Residual errors are distributed normally: $\epsilon \sim \mathcal{N}(0, \sigma^2)$.

Q-Q Plot / Shapiro
P-Value Validity
AUDIT

If residuals deviate on Q-Q tails, standard errors and p-values are invalid. Use bootstrapping.

E

Equal Variance

Homoscedasticity: Error variance is constant across all fitted values.

Breusch-Pagan Test
No Fan-Out
AUDIT

Heteroscedasticity (fan-out cone) invalidates t-test confidence intervals. Use Huber-White robust errors.

M

Multicollinearity

Predictors must not be highly correlated with each other.

$\text{VIF} < 5.0$
Ridge / PCA
AUDIT

$\text{VIF} > 10$ indicates severe coefficient instability. Drop redundant feature or apply Ridge regression.

HYPOTHESIS TESTING FRAMEWORK

Statistical Testing: T-Test vs. ANOVA vs. Chi-Square

Parametric tests vs. non-parametric fail-safes when LINE+M assumptions collapse.

TEST SELECTION
2 CONTINUOUS GROUPS Flip ⟳

Two-Sample T-Test

Compares the means of two independent groups (e.g. Length of stay for Readmitted vs. Non-Readmitted).

$t = \frac{\bar{x}_1 - \bar{x}_2}{\sqrt{\frac{s_1^2}{n_1} + \frac{s_2^2}{n_2}}} \quad (\text{Welch's t-test})$
  • Always use Welch's: Never assume equal variances in real-world data.
  • Non-Parametric: Mann-Whitney U test (if normality fails).
EVALUATION RULE

Welch's vs. Student's

Student's t-test assumes $\sigma_1^2 = \sigma_2^2$. If this fails, Type I error inflates heavily. Welch's t-test automatically adjusts degrees of freedom without statistical power penalty.

≥3 CONTINUOUS GROUPS Flip ⟳

One-Way ANOVA

Tests whether the means of 3 or more groups differ (e.g. Lab procedures across Age brackets: <30, 30–60, >60).

$F = \frac{\text{Between-Group Variance (MSB)}}{\text{Within-Group Variance (MSW)}}$
  • Post-Hoc: Tukey's HSD test reveals exactly which pairs differ.
  • Non-Parametric: Kruskal-Wallis H test (rank-based).
MULTIPLE COMPARISONS

Why Not Multiple T-Tests?

Running 3 separate t-tests across 3 groups compounds family-wise error rate: $\alpha_{\text{total}} = 1 - (1 - 0.05)^3 = 14.3\%$. ANOVA controls global $\alpha = 0.05$ in a single omnidirectional test.

CATEGORICAL VS CATEGORICAL Flip ⟳

Chi-Square Independence

Tests association between two categorical variables (e.g. Readmission Status vs. Admission Source).

$\chi^2 = \sum \frac{(O - E)^2}{E} \quad df = (r-1)(c-1)$
  • Expected Frequency: $E_{ij} = \frac{\text{Row Total} \times \text{Col Total}}{\text{Grand Total}}$.
  • Requirement: $E_{ij} \ge 5$ in every cell. If violated, use Fisher's Exact Test.
CONTINGENCY AUDIT

Cochran's Rule

If more than 20% of contingency table cells have expected counts <5, the asymptotic $\chi^2$ distribution fails. Combine sparse categories or execute Fisher's exact permutation test.

ORAL DEFENSE
CHALLENGE 01 · LITTLE'S TEST Flip for Response ⟳

"Little's MCAR test returned $p = 0.0001$. Can you use Mean Imputation?"

Defend your missingness strategy before a panel that prefers simple mean substitution.

MAR / MNAR Rejection
MODEL ORAL DEFENSE

"Absolutely not. A p-value of 0.0001 decisively rejects the null hypothesis that data is Missing Completely at Random. Missingness is systematically correlated with observed or unobserved covariates (MAR or MNAR). Substituting the mean would artificially collapse variance, bias regression slopes, and distort demographic risk profiles. We must deploy conditional group-wise imputation, MICE, or explicit missingness indicators."

CHALLENGE 02 · DUMMY TRAP Flip for Response ⟳

"Why does failing to drop a category in One-Hot Encoding cause linear regression to fail?"

Explain the linear algebra singularity behind the Dummy Variable Trap.

Matrix Non-Invertibility
MODEL ORAL DEFENSE

"When keeping all $k$ dummy columns alongside the intercept $x_0$, the sum of the dummy vectors $\sum D_j$ equals exactly 1. This creates perfect multicollinearity. The columns of design matrix $X$ are linearly dependent, causing $X^TX$ to have a zero determinant ($\det(X^TX) = 0$). Because a singular matrix has no inverse, the OLS estimator $(X^TX)^{-1}X^TY$ cannot be solved. We must drop one reference category ($k-1$ encoding)."

CHALLENGE 03 · T-TEST SELECTION Flip for Response ⟳

"Why should Welch's t-test always be default over Student's t-test?"

Defend non-pooled degrees of freedom in clinical and observational research.

Heteroscedasticity Robustness
MODEL ORAL DEFENSE

"Student's t-test assumes equal variances ($\sigma_1^2 = \sigma_2^2$). In observational data, sample sizes and group variances are almost never identical. When sample sizes are unequal and variance is higher in the smaller group, Student's t-test inflates the Type I error rate well above 0.05. Welch's t-test adjusts the degrees of freedom using the Welch-Satterthwaite equation, maintaining exact 5% error without losing statistical power if variances happen to be equal."

CHALLENGE 04 · WINSORIZATION Flip for Response ⟳

"Why Winsorize extreme clinical values instead of trimming them?"

Explain leverage reduction versus sample size preservation in medical epidemiology.

Leverage vs Sample Size
MODEL ORAL DEFENSE

"Trimming outliers deletes entire rows, shrinking sample size $N$ and discarding legitimate high-risk patient records. Winsorization clamps extreme values at the 5th and 95th percentiles. This preserves 100% of the sample size and patient clinical history while neutralizing extreme leverage points that would otherwise skew regression slopes and distort gradient updates."
