2. THE IMPUTATION CONFESSION
--------------------------------------------------------------------------------
You mentioned that you knew about imputations in theory, but had no idea what
imputation to choose or what damage blind imputation would cause.

Q2.1: Did you ever run something like df.fillna(df.mean()) or a forward-fill
      that resulted in a crazy, nonsensical result or distorted graph?
[YOUR ANSWER HERE]: Yes. I used to think missing values just meant "zero" or
could simply be filled in with a quick mean. But looking at numbers alone doesn't
give us the whole picture. When you naively impute without checking the
underlying distribution, it creates artificial clusters and warps your graphs.

Q2.2: What was the biggest "aha!" moment when learning about why naive
      imputation is dangerous?
[YOUR ANSWER HERE]: Realizing that numbers alone can lie, and you always have
to visualize the feature before touching it. Missingness itself is often a signal
rather than just empty space.

--------------------------------------------------------------------------------
Q4.1: When you open a brand new dataset in Jupyter today, what are the first 3
      Python commands or functions you immediately type in your notebook?
[YOUR ANSWER HERE]: `df.info()`, `df.describe()`, and `df.isna().sum()`.
I always run these single-column audits first before deciding which features need
univariate, bivariate, or multivariate inspection.

Q4.2: Are there any particular visual libraries or workflows you love using most?
[YOUR ANSWER HERE]: Seaborn and Matplotlib for clean, expressive plotting.
Also, our team's breakthrough workflow: using GitHub as our raw dataset
directory! When working on Google Colab in groups, teammates always ran into
Google Drive file path errors (`/content/drive/MyDrive/...`) because Google Colab
doesn't persist files unless everyone has the exact same folder structure.
By uploading the raw CSV to GitHub and reading directly from the raw GitHub URL,
our whole group can run the notebook seamlessly without directory errors.
