The ReAct Reasoning Loop

AGENTIC REASONING

Reasoning + Acting in Harmony

How cognitive agents break complex problems into iterative tool-use steps.

  • 1. Thought: The LLM generates an internal reasoning trace evaluating its current progress.
  • 2. Action: The LLM selects and calls a specific tool with structured JSON arguments.

The Broken AIMessage Call

CLICK OR TAB TO FLIP ↻
SYNTAX & TYPE TRAP

Spotting the AIMessage Bug

A classic exam question analyzing broken LangChain code snippets.

  • Broken Snippet:
    chain = prompt | llm
    res = chain.invoke({"q": "hi"})
    print(res.upper())
  • The Bug: res is an AIMessage, not a string! Calling .upper() triggers a fatal AttributeError.
  • The Fix: Either append StrOutputParser() to the chain or print res.content.upper().

ENVIRONMENT TRAPS

Solving .env.txt and HTTP 429

Resolving the two most frequent student environment errors.
